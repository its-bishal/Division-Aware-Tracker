# Kalman-LDDMM Tracker – Mathematical Overview

## 1. Constant-Velocity Kalman Filter

The state vector for a tracked cell is

$$ \mathbf{x}_k = [x,\;y,\;a,\;h,\;v_x,\;v_y,\;v_a,\;v_h]^\top, $$

where $(x,y)$ are the centroid coordinates, $a$ is the aspect ratio, $h$ is the height, and the last four components represent their respective velocities.

### Prediction

For a time step of $\Delta t = 1$ frame, the prediction equations are

$$ \mathbf{x}_{k|k-1} = \mathbf{F}\mathbf{x}_{k-1|k-1}, $$

$$ \mathbf{P}_{k|k-1} = \mathbf{F}\mathbf{P}_{k-1|k-1}\mathbf{F}^\top + \mathbf{Q}, $$

where the state-transition matrix is

$$ \mathbf{F} = \begin{bmatrix} \mathbf{I}_4 & \Delta t\,\mathbf{I}_4 \\ \mathbf{0}_4 & \mathbf{I}_4 \end{bmatrix}. $$

The process-noise covariance $\mathbf{Q}$ is diagonal and scales with the current cell height $h$ (see `kalman_filter.py`).

### Measurement Update

When a detection $\mathbf{z}_k$ (bounding box in image space) is available, the innovation is

$$ \mathbf{y}_k = \mathbf{z}_k - \mathbf{H}\mathbf{x}_{k|k-1}. $$

The innovation covariance is

$$ \mathbf{S}_k = \mathbf{H}\mathbf{P}_{k|k-1}\mathbf{H}^\top + \mathbf{R}.$$

The Kalman gain is

$$ \mathbf{K}_k = \mathbf{P}_{k|k-1} \mathbf{H}^\top \mathbf{S}_k^{-1}. $$

The updated state and covariance are

$$ \mathbf{x}_{k|k} = \mathbf{x}_{k|k-1} + \mathbf{K}_k\mathbf{y}_k, $$

$$ \mathbf{P}_{k|k} = \left( \mathbf{I} - \mathbf{K}_k\mathbf{H} \right) \mathbf{P}_{k|k-1}. $$

Here, $\mathbf{H}$ extracts the first four components of the state (position-related measurements), while $\mathbf{R}$ is the measurement-noise covariance and is also height-scaled.

The Kalman filter therefore provides a **linear-Gaussian prediction** of where a cell is expected to appear in the next frame. A Mahalanobis-based gating distance, using `chi2inv95`, determines whether a detection is sufficiently compatible with the prediction.

## 2. Large-Deformation Diffeomorphic Metric Mapping (LDDMM)

When a tracked cell divides, a linear-Gaussian motion model is insufficient because the shape of the parent cell deforms into two daughter cells.

LDDMM treats this as an optimal-transport-like registration problem between the binary mask of the parent, $\mathbf{I}_p$, and the combined mask of the candidate daughters, $\mathbf{I}_d$.

### 2.1 Velocity-Field Formulation

We seek a time-dependent velocity field

$$ \mathbf{v}(\mathbf{x},t) $$

defined on the image domain $\Omega$.

The deformation is generated by the flow

$$ \frac{\partial \phi_t(\mathbf{x})}{\partial t} = \mathbf{v}\left(\phi_t(\mathbf{x}),t\right), \qquad \phi_0(\mathbf{x})=\mathbf{x}. $$

After unit time, the warped source image is

$$ \mathbf{I}_p \circ \phi_1^{-1}. $$

### 2.2 Energy Functional

LDDMM minimizes an energy consisting of a data-attachment term and a regularization term:

$$ E(\mathbf{v}) = \underbrace{ \mathcal{D} \left( \mathbf{I}_p\circ\phi_1^{-1}, \mathbf{I}_d \right) }_{\text{data attachment}} + \lambda \underbrace{\int_0^1 \left\| \mathbf{v}(\cdot,t) \right\|_{\mathcal{H}}^2 \,dt }_{\text{kinetic energy}}. $$

The data-attachment term $\mathcal{D}$ can be either:

1. **Mean Squared Error (MSE)** — Model A
2. **Unbalanced Sinkhorn divergence** — Model B

The Sinkhorn formulation is provided by the `geomloss` library and allows mass creation/destruction, which is useful when comparing a single parent with multiple daughter-cell regions.

The RKHS norm $\|\cdot\|_{\mathcal{H}}$ is induced by a Gaussian kernel with bandwidth $\sigma$, configured through `lddmm_sigma`.

The regularization parameter $\lambda$ is implicitly incorporated into the optimization step size through `lddmm_step_size`.

### 2.3 Discretization and Optimization

The velocity field is discretized on a regular image grid of size $H\times W$. Consequently,

$$ \mathbf{v}\in\mathbb{R}^{2HW}. $$

Gradient descent is then used to minimize the energy:

$$ \mathbf{v}^{(t+1)} = \mathbf{v}^{(t)} -\eta \nabla_{\mathbf{v}} E\left(\mathbf{v}^{(t)}\right),$$

where $\eta$ is the learning rate specified by `lddmm_step_size`.

The gradient of the kinetic-energy term is computed analytically through kernel convolution.

The gradient of the data-attachment term depends on the selected loss:

- **MSE:** uses the standard squared-error gradient.
- **Sinkhorn:** uses the gradient of the regularized optimal-transport divergence provided by `geomloss.SamplesLoss` with `backend="tensorized"`.

To keep memory usage tractable, the implementation operates only on **active pixels**, i.e. pixels where either the parent or daughter mask is non-zero. This behavior is implemented in `tracking/lddmm.py`.

## 3. Integration into the Tracking Pipeline

The Kalman-LDDMM tracker operates in three main stages.

### 3.1 Association

The Kalman filter first performs motion prediction and gating, producing a set of candidate parent-daughter associations.

### 3.2 LDDMM Cost

For each candidate association, the LDDMM registration cost is computed as

$$ E_{ij} = \operatorname{compute\_lddmm\_cost} \left(\mathbf{I}_{p_i}, \mathbf{I}_{d_j}, \text{config} \right).$$

Here, $\mathbf{I}_{p_i}$ is the mask of parent $i$ and
$\mathbf{I}_{d_j}$ is the combined mask of the candidate daughter
configuration $j$.

### 3.3 Mitosis Decision

The candidate pair is accepted as a mitosis event when

$$ E_{ij} < E_{\mathrm{threshold}},$$

where $E_{\mathrm{threshold}}$ is the value configured by `lddmm_energy_threshold`. Otherwise, the candidate tracks remain independent.

## 4. Configurable Tracker Variants

The implementation exposes `lddmm_loss_type` and `kalman_filter_type` in `utils/configs.py`, allowing different tracking configurations to be evaluated using the same codebase.

| Configuration | Motion Model | Deformation Model | Description |
|---|---|---|---|
| **Baseline Kalman** | KF | None | Fast baseline without LDDMM |
| **KF + LDDMM (MSE)** | KF | LDDMM + MSE | Classical diffeomorphic registration |
| **KF + LDDMM (Sinkhorn)** | KF | LDDMM + Sinkhorn | OT-aware deformation model |
| **UKF variants** | UKF | Optional LDDMM | Nonlinear covariance propagation |
